# Skills

Custom instructions and prompts for AI agents.

## Overview

This repository contains reusable instruction sets designed to optimize AI agent behavior and performance. These instructions serve as foundational configurations for Claude and other AI-powered systems.

## Files

- **AGENTS.md** - System prompts and behavioral guidelines for AI agents
- **CLAUDE.md** - Claude-specific configurations and instructions

## Setup

1. Copy `AGENTS.md` and `CLAUDE.md` to your project root
2. Customize as needed for your specific use case
3. Reference these files when initializing AI agents

## Recommended Resources

For a comprehensive collection of high-quality skills and prompts, check out [mattpocock/skills](https://github.com/mattpocock/skills) — widely considered one of the most valuable skill sets available.

## Philosophy

Effective AI instruction is rooted in clarity and specificity:

- **Keep it concise** — Remove unnecessary verbosity
- **Be specific** — Provide concrete examples and requirements
- **Avoid assumptions** — State expectations explicitly
- **Let the model work** — Don't overcomplicate; the LLM will handle the rest

The most powerful instructions are often the shortest ones. Focus on what matters, and the AI will take care of the implementation details.
